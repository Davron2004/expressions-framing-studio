# Shared integration contract

Root owns package/config, catalog.ts, main studio UI, global CSS and layout. Agents may not change those without asking. Other agents work only assigned files. No Sites tooling or deployment by subagents; explicit user wants delegated Next.js/Railway code. Use imports @/*.

Catalog Configuration, Quote, dimensions and options live in src/lib/catalog.ts. Server treats all client inputs as untrusted. Quote POST /api/quote body Configuration, response Quote. Checkout POST /api/checkout body {configuration: Configuration, idempotencyKey: string}, response {url:string,orderId:string} or {error:string} with non-2xx. Amount never provided by browser. Quote total CAD cents. GET /api/orders returns {orders: PublicOrder[], configured:boolean}; GET /api/orders/[id] returns {order:PublicOrder}. PublicOrder {id,status:'pending'|'paid'|'expired',configuration,total,currency,createdAt,paidAt}. Exclude Stripe/payment/customer identifiers from public orders responses. Photo is local sample path or validated image data URL. Store normalized uploaded JPEG only, max 2MB decoded. UI resizes upload before request. Success route /order/[id]. No fake payments or fake paid orders when credentials unavailable; return clear unavailable state. Checkout cancel URL /?checkout=cancelled. Root page restores config from sessionStorage if possible.

FramePreview default export src/components/frame-preview.tsx props {configuration:Configuration;mode:'studio'|'room';className?:string}. Render transparent canvas and accessible fallback. Root owns surrounding staging and controls. No global CSS changes from agent.
